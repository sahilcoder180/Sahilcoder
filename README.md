# 🏎️ Python Kivy Car Racing Game

## 🎮 Game Features
- Endless car racing with touch controls
- Speed increases as your score goes up
- Colorful enemy trucks with collision detection
- Real-time Score & Speed display
- Game Over screen with Restart option

## 🛠️ Built With
- **Language:** Python 3
- **Framework:** Kivy
- **Concepts:** Object-Oriented Programming, Game Loop

## 🚀 How to Run
1. Install Kivy: `pip install kivy`
2. Run the game: `python main.py`
3. Drag your finger to move the car and avoid trucks!
